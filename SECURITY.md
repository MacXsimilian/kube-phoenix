# Security Policy

## Reporting a Vulnerability

Please report security vulnerabilities via GitHub's private vulnerability reporting:
https://github.com/MacXsimilian/kube-phoenix/security/advisories/new

We aim to acknowledge reports within **72 hours** and provide a fix or
mitigation within 90 days of disclosure.

Please do not report security vulnerabilities through public GitHub issues.

## Supported Versions

| Version | Supported |
|---------|-----------|
| 0.6.x   | ✅        |
| < 0.6   | ❌        |

## Disclosure Policy

Once a report is received, we will:

1. Confirm the vulnerability and determine its impact.
2. Prepare a fix and release it in a patch version.
3. Publicly disclose the issue via a GitHub Security Advisory after the fix is released.
